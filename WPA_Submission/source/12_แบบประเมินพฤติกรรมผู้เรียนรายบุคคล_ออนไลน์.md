# แบบประเมินพฤติกรรมผู้เรียนรายบุคคล — ระบบออนไลน์

รายวิชา **เทคโนโลยี (วิทยาการคำนวณ 1) ว31101**  
ชั้นมัธยมศึกษาปีที่ 4 • หน่วยที่ 3 การพัฒนาโครงงาน — AI to ESP32

ระบบออนไลน์: `behavior-assessment.html`

## จุดประสงค์

ใช้บันทึกหลักฐานด้านคุณลักษณะและพฤติกรรมของผู้เรียนเป็นรายบุคคลระหว่างการจัดกิจกรรม Active Learning / Collaborative Learning โดยไม่ใช้แทนหลักฐานผลสัมฤทธิ์ด้านความรู้และทักษะปฏิบัติ

## ตัวชี้วัด 6 ด้าน

1. **มีวินัย** — ปฏิบัติตามข้อตกลง บทบาท เวลา และขั้นตอนการทำงาน
2. **ใฝ่เรียนรู้** — สนใจค้นหา ทดลอง ตั้งคำถาม และใช้หลักฐานเพื่อเรียนรู้
3. **มุ่งมั่นในการทำงาน** — พยายามทำงานและแก้ปัญหาต่อเนื่องเมื่อพบอุปสรรค
4. **ความรับผิดชอบ** — ปฏิบัติงานตามบทบาท ดูแลอุปกรณ์ และส่งต่องานให้กลุ่มครบถ้วน
5. **การยอมรับ/รับฟังผู้อื่น** — รับฟังความคิดเห็น แลกเปลี่ยนเหตุผล และตัดสินใจร่วมกันโดยใช้หลักฐาน
6. **การใช้เทคโนโลยีอย่างเหมาะสมและปลอดภัย** — ใช้อุปกรณ์ ซอฟต์แวร์ กล้อง เครือข่าย และข้อมูลอย่างเหมาะสมกับกิจกรรมและคำนึงถึงความปลอดภัย

## เกณฑ์คะแนน 3 ระดับ

| คะแนน | ระดับ | แนวพิจารณา |
|---:|---|---|
| 3 | ดี | แสดงพฤติกรรมได้ชัดเจนและสม่ำเสมอ โดยทำได้ด้วยตนเอง |
| 2 | พอใช้ | แสดงพฤติกรรมได้เป็นส่วนใหญ่หรือเป็นบางครั้ง อาจต้องมีคำแนะนำเล็กน้อย |
| 1 | ควรปรับปรุง | ยังแสดงพฤติกรรมไม่ชัดเจน ต้องได้รับการกระตุ้น กำกับ หรือส่งเสริมเพิ่มเติม |

คะแนนเต็มต่อคน = **18 คะแนน**  
ระบบคำนวณค่าเฉลี่ยจากคะแนนที่บันทึกเพื่อช่วยสรุปข้อมูล แต่ครูควรพิจารณาร่วมกับหลักฐานจริงในชั้นเรียน

## วิธีใช้งานระบบ

1. ครูเปิด `behavior-assessment.html`
2. กรอกรหัสครู เลือกวันที่ และเลือกห้อง ม.4/1–ม.4/13
3. กด **โหลดรายชื่อ** ระบบจะเรียงตามเลขที่
4. เลือกคะแนน 1–3 จาก Dropdown ในแต่ละตัวชี้วัด
5. ใส่หมายเหตุรายบุคคลได้ตามความจำเป็น
6. กด **บันทึกทั้งหมด** เพื่อบันทึกเข้า Supabase
7. เปิดแท็บ **สรุปผล** เพื่อดูค่าเฉลี่ยรายตัวชี้วัดและรายบุคคล
8. สามารถแก้คะแนนแล้วบันทึกใหม่ได้ โดยระบบจะอัปเดตข้อมูลของวันที่/ห้อง/เลขที่เดิม
9. หากรายชื่อยังไม่ครบ สามารถกด **นำเข้ารายชื่อ** แล้ววางข้อมูลรูปแบบ `เลขที่,ชื่อ-สกุล` หรือคัดลอกจาก Excel 2 คอลัมน์

## การจัดการข้อมูล

ระบบใช้ตาราง
- `student_roster` สำหรับรายชื่อนักเรียนแยกตามห้องและเลขที่
- `behavior_assessments` สำหรับคะแนนรายตัวชี้วัดตามวันที่ประเมิน

การอ่าน/เขียนข้อมูลทำผ่าน Supabase Edge Function `teacher-behavior-admin` ซึ่งตรวจรหัสครูก่อนดำเนินการ และไม่ได้เปิดสิทธิ์อ่าน/แก้ไขตารางโดยตรงให้ผู้ใช้งานทั่วไป

## การใช้เป็นหลักฐาน วPA

ข้อมูลจากแบบประเมินนี้เหมาะสำหรับใช้เป็นหลักฐานประกอบด้านพฤติกรรมและคุณลักษณะ เช่น การทำงานตามบทบาท การรับฟังสมาชิก ความรับผิดชอบ ความมุ่งมั่นในการ Debugging และการใช้เทคโนโลยีอย่างเหมาะสม โดยควรพิจารณาร่วมกับ
- ใบกิจกรรม 3 Stations
- System Flow / IPO
- Challenge Before–Feedback–After
- Mentimeter ท้าย Explore
- Application Design Card
- การสุ่มถามสมาชิก
- ผลการปฏิบัติจริง
