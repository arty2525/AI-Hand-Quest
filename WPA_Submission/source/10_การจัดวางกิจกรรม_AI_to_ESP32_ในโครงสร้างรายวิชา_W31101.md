# การจัดวางกิจกรรม AI to ESP32 ในโครงสร้างรายวิชา ว31101
## โครงสร้างรายวิชา → หน่วยการเรียนรู้ → 5E 50 นาที → หลักฐาน วPA

## 1. ตำแหน่ง
กิจกรรมอยู่ใน **หน่วยที่ 3 การพัฒนาโครงงาน** เป็นหลัก

- หน่วย 1: แนวคิดเชิงคำนวณ
- หน่วย 2: การแก้ปัญหาและขั้นตอนวิธี
- หน่วย 3: นำความรู้ไปออกแบบ พัฒนา ทดสอบ ปรับปรุง และนำเสนอ

AI to ESP32 คือบริบทสำหรับประยุกต์แนวคิดเชิงคำนวณ ไม่ใช่หน่วย AI แยก

## 2. ชื่อกิจกรรม
**การพัฒนาต้นแบบระบบควบคุมแบบไม่สัมผัสด้วย AI และ ESP32 โดยใช้แนวคิดเชิงคำนวณ**

## 3. ความเชื่อมโยง

| เนื้อหารายวิชา | การใช้ |
|---|---|
| การแยกย่อยปัญหา | Webcam / Browser / AI / HTTP / ESP32 / Output |
| การหารูปแบบ | เปรียบเทียบอาการผิดพลาด |
| การคิดเชิงนามธรรม | IPO / System Flow |
| การแก้ปัญหาด้วยคอมพิวเตอร์ | Test / Debug |
| ขั้นตอนวิธี | Data Flow / ลำดับตรวจสอบ |
| โครงงาน | Prototype → Test → Feedback → Improve |
| ชีวิตจริง | Application Design |

## 4. ลำดับ 22 ชั่วโมง

1–2 ตัวอย่างโครงงานและปัญหาชีวิตจริง  
3–4 กำหนดปัญหา/ความต้องการ  
5–6 IPO / System Flow  
7–8 Prototype v1  
**9 คาบ วPA: 5E Integration + Debugging + Mentimeter Formative Check-in + Feedback + Application**  
10–11 ปรับ AI  
12–13 ปรับ ESP32  
14–15 Integration Test  
16–17 Debugging & Improvement  
18–19 Application Design  
20 Test & Summary  
21 Report  
22 Show Time

## 5. โครงคาบชั่วโมงที่ 9

| ขั้น | เวลา | จุดเน้น |
|---|---:|---|
| Engage | 5 | Fault Demo + คำถามหลักฐาน |
| Explore | 11 | 3 Stations |
| Explore Check-in | 4 | Mentimeter Q1/Q2 |
| Explain | 8 | ใช้ผล Menti เป็นฐานอธิบาย |
| Elaborate | 14 | Challenge + Before/After + Application |
| Evaluate | 8 | สุ่มถาม + Post-test + Dashboard |

Mentimeter อยู่ **ท้าย Explore ก่อน Explain** ไม่ใช้แทน Stations และไม่ใช้เป็นคะแนนหลัก

## 6. หลักฐานความสอดคล้อง

1. Problem Statement
2. IPO / System Flow
3. Prototype
4. Station Evidence
5. Mentimeter Q1/Q2 + คลิป Menti → Explain
6. Challenge Debugging
7. Before/After Feedback
8. Application Design
9. Post-test / Dashboard
10. Project Report / Show Time

## 7. สิ่งที่ไม่เปลี่ยน

- มาตรฐาน ว 4.2
- ตัวชี้วัด ม.4/1
- หน่วยที่ 3 ตามโครงสร้างรายวิชา
- น้ำหนักคะแนนรายวิชาโดยอัตโนมัติ

## 8. บทบาทเครื่องมือ

- **AI Hand Quest:** สื่อ/Pre-Post/เครื่องมือประเมิน
- **Mentimeter:** Formative Assessment ท้าย Explore + หลักฐานความคิดรายกลุ่ม
- **Supabase / Teacher Dashboard:** บันทึกและสรุปผล Pre/Post

เครื่องมือเหล่านี้ไม่ใช่สาระหลัก เว้นแต่มีแผนเฉพาะกำหนดไว้
