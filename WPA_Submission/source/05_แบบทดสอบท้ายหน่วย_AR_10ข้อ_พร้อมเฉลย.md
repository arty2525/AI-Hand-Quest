# แบบทดสอบหลังเรียน 10 ข้อ พร้อมเฉลย
## หน่วยที่ 3 การพัฒนาโครงงาน — ต้นแบบระบบควบคุมแบบไม่สัมผัสด้วย AI และ ESP32

เกณฑ์ผ่าน 70% = 7/10

---

### ข้อ 1
ระบบควบคุมไฟแบบไม่สัมผัสใช้กล้องรับภาพมือ AI จำแนกภาพ และ ESP32 สั่ง LED ในกรอบ Input–Process–Output ข้อใดถูกต้องที่สุด?

A. Input = ภาพจากกล้อง, Process = AI ใน Browser วิเคราะห์ภาพ, Output = ESP32 ควบคุม LED  
B. Input = LED, Process = ESP32 ถ่ายภาพ, Output = Webcam  
C. Input = ESP32, Process = LED, Output = AI  
D. Input = Wi-Fi, Process = LED, Output = Class

**เฉลย: A**

### ข้อ 2
ในต้นแบบที่ใช้ Teachable Machine + TensorFlow.js ส่วนใดประมวลผลโมเดล AI?

A. Web Browser  
B. LED  
C. GPIO  
D. ESP32 โดยตรง

**เฉลย: A**

### ข้อ 3
หน้าที่หลักของ ESP32 ในต้นแบบนี้คือข้อใด?

A. รับ HTTP Request ผ่าน Web Server และควบคุม GPIO/Output  
B. Train โมเดล Teachable Machine  
C. เปิด Webcam ของคอมพิวเตอร์  
D. สร้าง Class Hand/No Hand

**เฉลย: A**

### ข้อ 4
Data Flow ใดถูกต้อง?

A. Webcam → Browser/AI → Prediction → HTTP → ESP32 → Output  
B. Output → ESP32 → Webcam → AI  
C. ESP32 → AI → Webcam → HTTP  
D. Browser → LED → AI → ESP32

**เฉลย: A**

### ข้อ 5
ถ้า `fetch('/on')` ทำงานตามที่ออกแบบ คำสั่งนี้มีบทบาทใด?

A. ส่ง HTTP Request ไปยัง Route `/on` ของระบบควบคุม  
B. Train โมเดลใหม่  
C. เปิด Webcam โดยตรง  
D. เปลี่ยน Class ใน Teachable Machine

**เฉลย: A**

### ข้อ 6
เปิด `/on` ด้วยตนเองแล้ว LED ติด แต่เมื่อ AI ตรวจพบ Hand แล้ว LED ไม่ติด สิ่งใดควรตรวจเป็นลำดับต้น ๆ?

A. Prediction และเงื่อนไข JavaScript/การส่ง HTTP จาก Browser  
B. เปลี่ยน LED ทันทีโดยไม่ทดสอบ  
C. ลบ Class ทั้งหมด  
D. เปลี่ยน ESP32 ทุกครั้ง

**เฉลย: A**

### ข้อ 7
AI สลับผล Hand/No Hand บ่อยแม้ว่ามือคงที่ วิธีปรับปรุงที่เหมาะสมคือข้อใด?

A. เพิ่มข้อมูลฝึกที่หลากหลายและใช้ Confidence/Stable Frames  
B. ส่ง `/on` และ `/off` พร้อมกัน  
C. ถอด Webcam ออก  
D. ลบข้อมูลฝึกทั้งหมด

**เฉลย: A**

### ข้อ 8
ข้อใดแสดงการใช้แนวคิด “แยกย่อยปัญหา” ในการ Debug ระบบได้ดีที่สุด?

A. แยกตรวจ Webcam → Prediction → HTTP → ESP32 Route → GPIO ทีละส่วน  
B. เปลี่ยนทุกอุปกรณ์พร้อมกัน  
C. กด Refresh ซ้ำโดยไม่เก็บหลักฐาน  
D. เดาสาเหตุจากผลลัพธ์อย่างเดียว

**เฉลย: A**

### ข้อ 9
ถ้า Webcam เปิดไม่ได้บนเว็บ สิ่งใดควรตรวจอย่างมีเหตุผลก่อน?

A. สิทธิ์กล้องและ Secure Context/HTTPS ของ Browser  
B. สีของ LED  
C. จำนวนขา GPIO  
D. Route `/off` เท่านั้น

**เฉลย: A**

### ข้อ 10
โรงพยาบาลต้องการลดการสัมผัสสวิตช์ในจุดล้างมือ แนวทางใดประยุกต์ต้นแบบได้เหมาะสมที่สุด?

A. ใช้กล้องเป็น Input, AI จำแนกท่าทางเป็น Process และ ESP32 ควบคุมอุปกรณ์เป็น Output พร้อมทดสอบความปลอดภัย  
B. ใช้ LED เป็น Input และให้กล้องเป็น Output  
C. ให้ ESP32 Train AI โดยไม่ใช้ข้อมูล  
D. เปิดอุปกรณ์ตลอดเวลาโดยไม่ตรวจผู้ใช้

**เฉลย: A**
