# โครงสร้างหลักฐานที่แนะนำ

**Pre-test 10 ข้อ → Problem/Prototype Context → 3 Stations → System Flow + IPO → Challenge Before Feedback → Feedback → Challenge After Feedback → Application Design → Post-test 10 ข้อ → Teacher Dashboard → บันทึกหลังสอน**

---

# การประเมิน

- Pre-test 10 ข้อ: Diagnostic ไม่คิดคะแนนผลสัมฤทธิ์
- ผลการปฏิบัติจริง: 90 คะแนน
- Post-test 10 ข้อ: 10 คะแนน
- รวม 100 คะแนน
- Post-test ผ่าน 70% = 7/10

ผล Pre/Post ถูกส่งเข้า Teacher Dashboard ผ่าน Supabase โดยอัตโนมัติ ไม่ต้องให้นักเรียนดาวน์โหลด CSV

---

# ลำดับเตรียมก่อนสอน/เก็บหลักฐาน

1. ระบุห้องเรียนและวันที่สอนจริงในแผน
2. ตรวจว่าเนื้อหาก่อนคาบนี้เชื่อมจาก IPO/System Flow และ Prototype v1
3. เตรียม Station A/B/C, Challenge Cards และ Application Design Cards
4. ทดสอบ AI Hand Quest, Webcam, ESP32 `/on` `/off` และ Teacher Dashboard
5. ทดสอบการส่งผลเข้า Supabase ด้วยข้อมูลจำลอง 1 คน แล้วลบข้อมูลทดสอบ
6. ระหว่างสอนเก็บ Before → Feedback → After ให้ชัด
7. หลังสอนเปิด Teacher Dashboard และบันทึกเฉพาะผลจริง
8. แนบตัวอย่าง System Flow, Debugging และ Application Design ของผู้เรียน
9. ตรวจว่าคลิปเห็นการคิด/ลงมือของผู้เรียนมากกว่าการบรรยายของครู
10. ตรวจหลักเกณฑ์ ก.ค.ศ./ต้นสังกัดฉบับปัจจุบันก่อนยื่นจริง
