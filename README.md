# AI Hand Quest — Teachable Machine × ESP32

เกม AR สำหรับนักเรียน ม.4 เพื่อเรียนรู้ Teachable Machine, AI บน Web Browser และ ESP32 ผ่าน MediaPipe Hands

## วิธีเล่น

1. เปิดหน้า GitHub Pages ของโปรเจกต์
2. กด `เข้าสู่เกม (Start)`
3. อนุญาตการใช้กล้อง
4. ใช้นิ้วชี้ควบคุม Cursor
5. จีบนิ้วโป้งกับนิ้วชี้เพื่อหยิบ/กด และกางนิ้วเพื่อปล่อย
6. หากกล้องใช้งานไม่ได้ สามารถใช้ Mouse หรือ Touch ได้
